# Universal DJ USB v0.3.0

A smoother GUI export, more reliable Traktor conversion, and portable folder layouts.

This release focuses on the desktop export workflow and the generated playlist files. The
GUI now locks itself while exporting, shows progress and logs, supports cancellation, and
can reveal the finished folder. Traktor NML paths now resolve correctly after moving the
export. Audio copying is available from both the GUI and the CLI.

## Highlights

### 🖥 A calmer GUI export

- Controls lock while an export is running.
- Log output, progress, and **Cancel** are available at the bottom of the window.
- Cancel stops between files and playlists and reports what completed.
- The completion dialog returns to the main tab and can reveal the output folder.
- The version label in the status bar opens a compact About dialog with repository and
  issue links.
- Audio-copy options live in the Conversion Options tab.
- Optional `PLAYLISTS/<FORMAT>/` layout keeps one shared copy of the audio.

### 🎛 Traktor NML conversion fixes

- NML `LOCATION` and `PRIMARYKEY` now come from the same volume-relative path pair.
- Fixes Traktor playlists that appeared empty or lost tracks when the `.nml` file was
  written outside the USB root.
- `FILE` uses the resolved filename, so renamed and Unicode files work.
- The relative/absolute path option now applies to **M3U/M3U8 only**, because NML has no
  such concept. See [ADR-0009](https://github.com/juanmartin/universal-dj-usb/blob/main/docs/adr/0009-nml-volume-relative-paths.md).

### 📦 Copy audio with the export

- Each playlist gets its own folder with flat, original filenames.
- `--number-files` prefixes tracks in playlist order (`01 - track.mp3`).
- Existing files are skipped by default; `--overwrite` replaces them.
- Duplicate filenames get a ` (2)`, ` (3)`, … suffix instead of overwriting.
- Missing files are reported and excluded from the generated playlist.
- The GUI and CLI share the same copy behavior.

### ⌨️ CLI additions

- New `udj copy-files` command, plus `--copy-files` for `udj convert`.
- New `--number-files`, `--overwrite`, and `--separate-format-folders` options.
- `udj --help` and the README list the exact syntax.

```bash
# Copy audio only; no playlist files are generated
udj copy-files /Volumes/USB ./export

# Convert and copy, with order numbers
udj convert /Volumes/USB -o ./export -f m3u8 --copy-files --number-files
```

## Bug fixes

- **Traktor NML:** `LOCATION`/`PRIMARYKEY` no longer disagree, fixing empty or incomplete
  Traktor playlists.
- **Windows:** missing absolute paths containing `Contents/` are re-anchored to the USB
  root instead of duplicating the USB prefix.
- **GUI:** the M3U extended-format tooltip now describes what the checkbox actually does.
- **macOS:** the app bundle version now matches `pyproject.toml`.
- **CI:** the Release workflow only runs for tag-driven builds, not pull requests.

## Known limitation

Some Rekordbox USB exports include both `export.pdb` and `exportLibrary.db`. The legacy
PDB can report incomplete playlist membership, so a generated playlist may be shorter than
expected. This release still reads the legacy PDB; OneLibrary support is planned next.
