# Universal DJ USB v0.3.0

Take a Rekordbox playlist from a USB drive to a folder you can carry anywhere.

This release adds **per-playlist audio copying**, fixes Traktor NML paths that could leave
playlists empty after moving an export, and turns the GUI export into a single,
cancellable workflow. Windows is now tested in CI alongside macOS and Linux.

## Highlights

### 📦 Copy the audio with the playlists

- New `udj copy-files` command, plus `--copy-files` for `udj convert`.
- Each playlist gets its own folder with flat, original filenames.
- `--number-files` prefixes tracks in playlist order (`01 - track.mp3`).
- Existing files are skipped by default; `--overwrite` replaces them.
- Duplicate filenames get a ` (2)`, ` (3)`, … suffix instead of overwriting.
- Missing files are reported and excluded from the generated playlist.
- The GUI exposes the same options; the main **Convert** button handles copy + convert,
  and the completion dialog can open the output folder.

```bash
# Copy only
udj copy-files /Volumes/USB ./export -p "Set A"

# Convert and copy, with order numbers
udj convert /Volumes/USB -p "Set A" -o ./export -f m3u8 \
  --copy-files --number-files
```

### 🎛 Traktor NML paths that resolve

- NML `LOCATION` and `PRIMARYKEY` now come from the same volume-relative path pair.
- Fixes Traktor playlists that appeared empty or lost tracks when the `.nml` file was
  written outside the USB root.
- `FILE` uses the resolved filename, so renamed and Unicode files work.
- The relative/absolute path option now applies to **M3U/M3U8 only**, because NML has no
  such concept. See [ADR-0009](https://github.com/juanmartin/universal-dj-usb/blob/main/docs/adr/0009-nml-volume-relative-paths.md).

### 🖥 A calmer GUI export

- Controls lock while an export is running.
- Log output, progress, and **Cancel** are available at the bottom of the window.
- Cancel stops between files and playlists and reports what completed.
- Optional `PLAYLISTS/<FORMAT>/` layout (`--separate-format-folders`) keeps one shared
  copy of the audio.
- The completion dialog returns to the main tab and can reveal the output folder.

## Bug fixes

- Fixed Traktor NML playlists with mismatched `LOCATION`/`PRIMARYKEY` paths.
- Fixed Windows path re-anchoring for missing absolute paths containing `Contents/`.
- Fixed the macOS bundle version metadata so it matches `pyproject.toml`.
- Clarified the M3U extended-format tooltip.
- The Release workflow now only runs for tag-driven builds, not pull requests.

Builds are unsigned. macOS Gatekeeper and Windows SmartScreen may warn on first launch.

## Known limitation

Some Rekordbox USB drives contain both `export.pdb` and `exportLibrary.db`, and the legacy
PDB can report incomplete playlists. This release still reads the legacy PDB. OneLibrary
support is the next planned parser change; the investigation is recorded in
[the OneLibrary plan](https://github.com/juanmartin/universal-dj-usb/blob/main/docs/plans/onelibrary-support.md).
